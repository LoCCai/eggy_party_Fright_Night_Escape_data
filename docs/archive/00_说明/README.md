# 网易《蛋仔派对》「逃出惊魂夜」资料归档包

**检索截止：2026-09-29**  
**资料范围：** 公开网页中可检索的官方公告、官方账号内容、官方公告镜像、社区 Wiki、攻略站、技能/地图图片索引等。

## 说明

本包按“资料库”方式整理，重点覆盖：

- 追捕角色、逃生角色、已公开的技能名称与机制摘要
- 1v4 / 2v8 核心玩法、逃生流程、煤炉/地下室/大门/痕迹/暴露等机制
- 地图及地图机制：惊魂马戏团、惊魂火车站、惊魂码头、惊魂不夜楼，以及历史资料中的地图提及
- 2024-07 至 2026-09 可检索到的平衡调整与玩法优化时间线
- 成长、徽章、多人同角色衰减、空间修正等系统资料
- 角色图、技能图、地图图的**原始来源与直链索引**
- 已知资料缺口与“尚未核验”项

## 可靠性分级

- **A：官方官网 / 官方公告**：用于版本、数字参数、正式机制变更的主依据。
- **B：网易官方账号视频/微博/Bilibili等官方发布**：用于角色技能演示、预告、视觉素材。
- **C：官方公告镜像 / 大型游戏平台同步**：用于补充和交叉验证。
- **D：社区 Wiki / 攻略站 / 论坛**：主要用于技能细节、角色背景、旧版本信息；可能存在滞后，不能单独作为“当前数值”的最终依据。

## 当前归档原则

1. **不把社区 Wiki 的旧页面直接当成 2026-09 的当前版本。**
2. 同一个机制出现多个数值时，优先采用时间更晚的官方调整公告，并在时间线注明历史值。
3. 尚未找到官方完整技能文本的角色，会标记为“需继续核验”，不臆造技能名称/数值。
4. 图片素材目前以“来源页面 + 原图 URL”形式归档。由于本运行环境对部分第三方图片域名存在网络访问限制，本包没有伪装成“已完整下载的所有原图”。
5. “至今所有”只能理解为**截至 2026-09-29、在本次可检索公开索引中发现的资料集合**；没有被搜索引擎收录、已删除、登录后可见或仅存在于客户端资源中的材料可能仍有遗漏。
